# Product screenshots

The landing page automatically uses the following product screenshots when they are present in this folder:

- `sillage-recall.webp` — main chat view with a grounded answer and visible citation
- `sillage-source.webp` — original note/source opened from a response
- `sillage-review.webp` — review or resurfacing view showing useful connections

Recommended export:

- WebP
- 2× pixel density
- no personal names, emails, API keys, private folder names, or sensitive note content
- consistent dark theme and accent color across all three images

Until these files are added, the landing page displays a representative fallback preview.
